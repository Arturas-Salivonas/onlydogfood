# Scoring Algorithm v3.0 - Quick Reference

## What Changed?

### ✅ Major Improvements

1. **Protein Diversity Scoring (NEW!)**
   - +5 points for foods with 6+ protein sources from 3+ categories
   - Rewards Orijen-style multi-protein formulas
   - Single-source foods get 0 points

2. **Grain Penalties 4X STRONGER**
   - Maize/corn as #1 ingredient: -8 points (was -2)
   - Brown rice now penalized: -1 to -4 points (was 0)
   - Multiple grains in top 5: -7 points (was -4)

3. **Better Ingredient Values**
   - Chicken meal: 4 points (was 1) - it's concentrated protein!
   - Fresh meats: NO MORE PENALTY - they're high quality
   - Organ meats: 3 points (was 2)
   - Whole eggs: 3 points (was 1)

4. **Stronger Penalties for Bad Stuff**
   - Low-value grains: -2 each (was -1)
   - Artificial colors: -7 (was -5)
   - Sugar: -5 (was -3)

### 📊 Expected Score Changes

## FAQ

**Q: Why does chicken meal score higher than fresh chicken?**
A: Chicken meal is dehydrated (300% more protein per pound). Fresh chicken is 70% water. Both are quality ingredients, but meal provides more protein density.

**Q: Will this hurt grain-inclusive formulas?**
A: Only grain-HEAVY formulas (grains in top 3-5). Quality foods with oats/barley as 6th-10th ingredient are fine.

**Q: What about sweet potato formulas?**
A: Sweet potato is not a grain - no penalty. It's a low-glycemic vegetable carb source.

**Q: How do I know if my product has good diversity?**
A: Count unique protein types:
- 1 type (e.g., only chicken) = 0 points
- 2 types (chicken + salmon) = 2-3 points
- 3+ types with 6+ sources = 5 points
